# ระบบเลือกโต๊ะเรียน 28 คน

เว็บ Next.js + Supabase สำหรับนักเรียน 28 คน (4 แถว x 7 โต๊ะ) มีล็อกอินด้วยเลขประจำตัว+ชื่อ, ตั้งเวลาเปิด/ปิดโดยแอดมิน, ฐานข้อมูลจริง และป้องกันการจองโต๊ะซ้ำด้วยฟังก์ชันฐานข้อมูลแบบ atomic

## สิ่งสำคัญก่อนใช้จริง
- การล็อกอินด้วยเลขประจำตัวและชื่อเป็นเพียงการตรวจสอบข้อมูล ไม่ใช่การยืนยันตัวตนที่แข็งแรง คนที่รู้ข้อมูลของเพื่อนอาจสวมรอยได้ หากต้องการปลอดภัยขึ้น ให้ใช้ PIN ที่แอดมินแจก หรือบัญชี Google ของโรงเรียน
- แอดมินมีรหัสผ่านเดียวจาก `ADMIN_PASSWORD`; ตั้งให้ยาวและไม่ซ้ำกับรหัสอื่น
- ไม่เปิดเผย `SUPABASE_SERVICE_ROLE_KEY` ในหน้าเว็บหรือในตัวแปร `NEXT_PUBLIC_...`
- โครงงานนี้ใช้การ refresh สถานะทุก 5 วินาที ไม่ใช่ Supabase Realtime จริง จึงเห็นการเปลี่ยนแปลงภายในประมาณ 5 วินาที
- แอดมินสามารถตั้งเวลาได้และเปิด/ปิดระบบ แต่รายชื่อนักเรียนจัดการจาก Supabase SQL Editor ตามขั้นตอนด้านล่าง

## 1. สร้างฐานข้อมูลฟรี
1. ไปที่ https://supabase.com แล้วสร้างโปรเจกต์ใหม่ (เลือกแพ็กเกจฟรีได้)
2. เปิด **SQL Editor > New query**
3. คัดลอกทั้งหมดจาก `supabase/schema.sql` ไปวาง แล้วกด Run
4. เพิ่มรายชื่อนักเรียน 28 คนใน SQL Editor ตัวอย่าง:

```sql
insert into public.students(student_id, full_name) values
('65001', 'ชื่อ นามสกุล 1'),
('65002', 'ชื่อ นามสกุล 2');
```

แทนที่ตัวอย่างด้วยเลขประจำตัวและชื่อจริงให้ครบ 28 คน ห้ามใช้เลขประจำตัวซ้ำ หากเพิ่มรายชื่อซ้ำจะเกิด error ซึ่งเป็นพฤติกรรมที่ถูกต้อง

## 2. ตั้งค่าโปรเจกต์ในเครื่อง
ต้องติดตั้ง Node.js เวอร์ชัน LTS ก่อน จากนั้นแตก ZIP แล้วเปิดโฟลเดอร์ `seat-selector` ใน VS Code

เปิด Terminal แล้วรัน:

```bash
npm install
```

คัดลอก `.env.example` เป็นไฟล์ `.env.local` แล้วกรอก:
- `NEXT_PUBLIC_SUPABASE_URL`: Supabase Project URL
- `SUPABASE_SERVICE_ROLE_KEY`: Supabase > Project Settings > API Keys > service_role/secret key
- `SESSION_SECRET`: สุ่มข้อความยาวอย่างน้อย 32 ตัวอักษร
- `ADMIN_PASSWORD`: ตั้งรหัสผ่านแอดมินที่เดายาก

**ห้ามแชร์ไฟล์ `.env.local` หรือเผยแพร่ Service Role Key**. อย่า commit ไฟล์นี้ลง GitHub

จากนั้นรัน:

```bash
npm run dev
```

เปิด http://localhost:3000

## 3. ทดลองระบบ
1. เข้าหน้าแอดมิน แล้วใส่ `ADMIN_PASSWORD`
2. ตั้งวันและเวลาเปิด/ปิด แล้วติ๊กเปิดใช้งานระบบและบันทึก
3. ออกจากระบบ แล้วเข้าสู่ระบบนักเรียนด้วยเลขประจำตัวและชื่อที่อยู่ในตาราง `students`
4. เมื่อถึงเวลาเปิด กดโต๊ะสีเขียวเพื่อเลือก
5. ทดสอบด้วยนักเรียนสองบัญชีเลือกโต๊ะเดียวกัน: คนที่กดสำเร็จคนแรกจะได้โต๊ะ ส่วนคนที่สองจะได้รับข้อความว่าโต๊ะไม่ว่าง
6. ทดสอบก่อนเวลาเปิดและหลังเวลาปิด ระบบต้องไม่ให้เลือก

## 4. นำขึ้นออนไลน์ฟรี
1. Push โฟลเดอร์นี้ไป GitHub โดยตรวจสอบว่า `.env.local` ไม่ได้ถูก commit
2. ไปที่ https://vercel.com แล้ว Import Git Repository
3. ตั้ง Environment Variables ตาม `.env.example` ในหน้า Project Settings ของ Vercel
4. Deploy แล้วแชร์ URL ที่ Vercel ให้กับเพื่อน
5. หากแก้ Environment Variables ต้อง Redeploy

Supabase และ Vercel มีแพ็กเกจฟรีที่อาจมีข้อจำกัดและเงื่อนไขเปลี่ยนแปลงได้ ควรตรวจสอบเงื่อนไขปัจจุบันก่อนนำไปใช้จริง

## 5. รีเซ็ตโต๊ะหลังจบกิจกรรม
ใช้ Supabase SQL Editor และตรวจสอบรายชื่อ/เวลาที่ต้องการก่อนสั่ง:

```sql
update public.seats
set student_id = null, student_name = null, selected_at = null;
```

คำสั่งนี้ล้างการเลือกโต๊ะทั้งหมด ควรทำโดยแอดมินเท่านั้น และควรสำรองข้อมูลก่อน

## โครงสร้าง
- `app/seat-app.tsx`: UI ภาษาไทย
- `app/api/*`: API ฝั่งเซิร์ฟเวอร์
- `lib/session.ts`: เซสชันแบบ signed HttpOnly cookie
- `lib/supabase.ts`: ตัวเชื่อม Supabase
- `supabase/schema.sql`: ตารางและฟังก์ชันเลือกโต๊ะ
